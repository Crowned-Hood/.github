# Crowned Hood Software

Crowned Hood Software is Roberto's software development project and GitHub organization, building software for software development services, music production, and games.

## What we build

- **MOOD**: an experimental Markdown-to-code compiler. It uses an LLM (Ollama) to generate code from Markdown descriptions, guided by object-oriented architecture, with the aim of cross-compiling to any language.
  - Repository: [Crowned-Hood/mood](https://github.com/Crowned-Hood/mood)

## Contributing

Issues and pull requests across Crowned Hood repositories use this repository's shared templates: bug reports, feature requests, and feature and bug-fix pull requests.
