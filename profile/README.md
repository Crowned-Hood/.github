# Crowned Hood Software

Crowned Hood Software is Roberto's software development project and GitHub organization.

## What we build

- **MOOD** — an experimental Markdown-to-code compiler. It uses an LLM (Ollama) to generate code from Markdown descriptions, guided by object-oriented architecture, with the aim of cross-compiling to any language.
  - Repository: [Crowned-Hood/mood](https://github.com/Crowned-Hood/mood)

## How we build

- **Web:** Vue with Nuxt
- **Apps:** React Native with Expo
- **Language:** TypeScript is the standard
- **Tools:** Bun is the runtime for tools that need to be made

## Presentation

Crowned Hood's presentation is inspired by the IBM Carbon Design System, with a wine-red primary colour on a dark background:

- Primary: wine red `#A6192E`
- Background: Carbon Grey 100 `#161616`

Graphical inspiration comes from Bring Me The Horizon's *That's The Spirit* — systematic Carbon presentation with a bit of edge.

## Contributing

Issues and pull requests across Crowned Hood repositories use the shared templates in this repository:

- **Bug report:** `.github/ISSUE_TEMPLATE/bug_report.md`
- **Feature request:** `.github/ISSUE_TEMPLATE/feature_request.md`
- **Pull requests:** `.github/PULL_REQUEST_TEMPLATE/feature.md` for features and `.github/PULL_REQUEST_TEMPLATE/bugfix.md` for bug fixes

Please fill in the relevant template, link any related issue, and describe how the change was tested.
