# Crowned Hood `.github`

This is the special `.github` repository for the Crowned Hood Software organization on GitHub.

It holds organization-wide content that GitHub applies across Crowned Hood repositories:

## Contents

- [`profile/README.md`](profile/README.md) — the organization description shown on the Crowned Hood organization profile.
- [`.github/ISSUE_TEMPLATE/bug_report.md`](.github/ISSUE_TEMPLATE/bug_report.md) — bug report issue template.
- [`.github/ISSUE_TEMPLATE/feature_request.md`](.github/ISSUE_TEMPLATE/feature_request.md) — feature request issue template.
- [`.github/PULL_REQUEST_TEMPLATE/feature.md`](.github/PULL_REQUEST_TEMPLATE/feature.md) — pull request template for feature changes.
- [`.github/PULL_REQUEST_TEMPLATE/bugfix.md`](.github/PULL_REQUEST_TEMPLATE/bugfix.md) — pull request template for bug fixes.

## Using the pull request templates

When opening a pull request, choose the template that matches the change:

- Feature: `?template=feature.md`
- Bug fix: `?template=bugfix.md`

For example, append `?template=feature.md` to the compare URL when creating a pull request.
